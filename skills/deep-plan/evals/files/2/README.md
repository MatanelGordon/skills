# Parcel Tracker

A small service that tells customers where their parcel is.

## How it works

1. A customer enters the tracking number on the status page.
2. The service asks the carrier for the latest scan.
3. You will recieve a confirmation email within a minute.

## Running it locally

```bash
npm install
npm start
```

The status page is then at http://localhost:3000.
