Integration notes
-----------------

No upstream skill, framework, corpus, command, script, or learning-log file is
vendored in this repository, and no substantive passage is copied verbatim. The file
`references/perception-first-lens.md` is an original, shortened adaptation of
the five-layer methodology for Impeccable Lite's bounded, local-only interface
workflow. It removes the broad automatic trigger, mandatory insight logs,
Ralph-loop repetition, numeric scoring, corpus loading, live URL workflow, and
fixed output ceremony. Changes were made to resolve conflicts with product
truth, accessibility, expert-interface density, offline execution, and bounded
verification. That reference is distributed under CC BY-SA 4.0. The remainder
of Impeccable Lite retains its existing MIT license except where another file
states otherwise.
