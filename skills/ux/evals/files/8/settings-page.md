# Settings page of our team chat app (desktop)

One flat page with 12 switches, in this order. "Changed by" is the share of
active users who moved the switch away from its default at least once in the
last 90 days.

| # | Switch | Default | Changed by | Note |
|---|---|---|---|---|
| 1 | Desktop notifications | On | 34% | |
| 2 | Notification sound | On | 27% | |
| 3 | Mute notifications outside working hours | Off | 41% | |
| 4 | Show message text in notifications | On | 12% | |
| 5 | Bounce the dock icon on a new message | On | 0.4% | |
| 6 | Mark a channel as read when I scroll to its end | On | 0.6% | |
| 7 | Use a 24-hour clock | Off | 0.3% | The system's clock format is not read today. |
| 8 | Send a message with Enter (off = Ctrl+Enter) | On | 9% | |
| 9 | High-contrast theme | Off | 0.8% | The system's contrast setting is not read today. |
| 10 | Ask before archiving a conversation | On | 46% | An archived conversation can be restored from the Archive tab at any time. |
| 11 | Show link previews | On | 6% | |
| 12 | Animate emoji | On | 0.5% | |

What we know:

- "I can't find the setting for ..." is the second most common kind of support
  ticket.
- In a test with 6 people, the median time to find the notification sound
  switch and turn it off was 48 seconds.
