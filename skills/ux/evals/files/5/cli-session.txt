A terminal session with snapkeep 2.3.0, a tool that keeps dated snapshots of a
folder. Lines starting with # are my notes, not output.

$ snapkeep --help
snapkeep 2.3.0

Usage: snapkeep <command> [options]

Commands:
  init      Create a snapshot store
  snap      take a snapshot of a folder
  ls        List snapshots
  restore   restore a snapshot
  rm        Remove a snapshot
  purge     remove snapshots

Options:
  init      -o <dir>         where the store lives
  snap      --target <dir>   where the store lives
  restore   --dest <dir>     where the restored files go
  ls        --format <fmt>   output format

$ snapkeep snap ~/projects --target /mnt/backup
